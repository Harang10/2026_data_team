# 고추 스마트팜 경제성 분석

처음 작성한 파이썬 프로그램을 보존한 버전입니다. 재배 규모, 초기 투자비, 운영비와 판매 단가를 입력하면 재배 1회 수익 및 목표 기간 내 투자금 회수 가능 여부를 계산합니다.

## Google Colab에서 실행

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Harang10/2026_data_team/blob/main/smartfarm_economics.ipynb)

노트북의 코드 셀을 실행한 뒤 안내에 따라 입력하세요. 판매 단가는 직접 입력해야 하며, 나머지 입력은 Enter를 누르면 기본값을 사용합니다.

## 로컬에서 실행

Python 3에서 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
python smartfarm_economics.py
```

## 파일

- `smartfarm_economics.py`: 처음 작성한 파이썬 원본
- `smartfarm_economics.ipynb`: 동일한 원본 코드가 들어 있는 Colab 노트북

생산량·전기요금 등은 원본의 가정값이며, 계산 결과는 실제 수익을 보장하지 않습니다.
