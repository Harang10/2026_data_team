# 팜인사이트

고추 스마트팜 경제성을 분석하는 한국어 웹앱입니다. 제공된 파이썬 계산식을 바탕으로 제작했습니다.

## 실행

Node.js에서 별도 의존성 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

```sh
npm test
```

## 기능

- 재배 규모, 목표 회수 기간, 판매 단가 및 모든 비용 가정을 슬라이더 또는 숫자로 입력
- 연간 운영이익, 단순 회수 기간, 누적 현금흐름, 비용 구성, 손익분기 단가
- 가격·생산량의 보수적/기준/낙관적 시나리오와 민감도 표
- 이 브라우저에 입력값 자동 저장, 초기화, CSV 결과 내보내기
- 반응형 레이아웃, 키보드 조작, 계산 기준 안내

`dist/`를 정적 웹서버에 게시할 수 있습니다. 서버 저장소나 사용자 계정 기능은 사용하지 않습니다. 기본값은 예시이며 실제 시세·요금에 연결되지 않습니다. 세금, 금융비용, 감가상각, 시설 수명 및 교체비, 토지비 등을 자동으로 반영하지 않습니다.
